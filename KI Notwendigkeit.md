Was muss die KI koennen

Fuers Animationsstudio:

- Bilder --> Mehrere Bilder werdedn zum Film
- Musik --> Hintergrund Musik gegenfalls
- Sprache --> Synchronisation dass die Figuren eine Stimme haben
- Script verstehen --> Bilder, Musik, Sprache zu kombinieren
- Video erstellen --> das Script befolgen

Fuer Spiele:

- Steuerung --> Maus, Tastatur oder Controller
- Modelle --> Spielfigur, NPC, Mobs, Bosse (Extern 2D oder 3D Figuren erstellen, oder das ganze in Python)
- Kampfsystem --> Fuer Kampfspiele (Was, Wieviel, Welche Bedingungen)
- Weltgeneration --> Welterstellung
- Script --> Einzelnen Stufen (Besonderheit Welt, z.B. mehrere Regionen)
